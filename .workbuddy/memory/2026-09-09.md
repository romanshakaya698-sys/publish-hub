## 无头/有头规则（用户 2026-09-09 上午明确，覆盖之前「永不弹窗」的老规则）

> 「你要给我弹你的操作流程…只有全自动和你检查的时候你在后台查」

- **confirm（预填待确认）模式 → headless=false 弹出可见窗口**：用户要看机器人的操作流程，最后自己点「发表」
- **auto（全自动）→ headless=true 后台静默**
- **助手检查/调试/状态抓取 → headless=true 后台**
- 同一 profile 不能双开 chromium：bot.js getContext 跨模式互斥——要有头先关无头；要无头时若有可见窗口（留给用户操作的）直接复用它开新 tab，避免冲突也不打扰用户
- 实现位置：publisher.js publishToPlatform `getContext(platformId, { headless: mode === 'auto' })`；已实测 confirm 弹窗预填成功

### ⚠️ 严重阻碍：网易号对 headless 反爬 / session 稳定性
- **headed 能进后台**（final URL 为 subscribe_v4 后台、编辑器正常 dump 出 DOM）。
- **headless 被强制踢回登录页**（`login.html?url=...#/`，页面带 `x-URS-iframe` 登录 iframe）。
- 即便某个时刻登录成功（第一次 publish 探测 dump 出编辑器），**数分钟后 cookie 失效又踢回登录页**。
  → 网易号登录态有效期很短 / 或每次打开都需重新校验。
- **corollary**：这对用户「auto（全自动）→ headless=true」的规则是**潜在冲突**——若网易强制杀 headless，
  网易号可能只能跑 confirm（有头）模式，auto 模式需另想办法（如降级为有头静默、或加 `--headless=new` 伪装）。
  **等用户登录确认后必须与用户确认此点。**

## CSDN 正文误填 AI 聊天修复（2026-09-09 晚）

### 问题根因
用户截图确认：CSDN confirm 模式下，正文被填到了**右侧内置 AI 助手聊天 iframe**（红框标注「这是聊天框 csdn内置的」），而左侧 Markdown 源码区仍是 CSDN 默认模板。
- `publisher.js` 旧 `fillContent` 会无脑遍历所有 `page.frames()`，把带 contenteditable 的第一个 iframe 当编辑器 → CSDN 的 AI 助手聊天 iframe 正好命中。
- CSDN 默认是 **Markdown 源码编辑器**（源码区 pre.editor__inner），不适合直接 insertHTML 富文本。

### 修复方案（lib/publisher.js）
- 重写 `fillContent`：平台感知分发
  - `platform.id === 'csdn'` → 走 `csdnFillContent`
  - `platform.contentMode === 'iframe'`（大鱼号 UEditor）→ 走 `fillFrameEditor`（只对显式声明 iframe 的平台开，避免误填辅助 iframe）
  - 其余（企鹅号 ProseMirror / 知乎 Draft.js）→ 走 `fillDomEditor`（主文档 contenteditable）
- 新增 `csdnFillContent`：先点「使用富文本编辑器」把 CSDN 切到富文本模式 → 精确选择器 `.editor__inner[contenteditable="true"]` → 兜底取「面积最大的可见 contenteditable」（避开右侧 AI 输入框）
- 新增 `fillFrameEditor` / `fillDomEditor` 两个小函数封装
- `lib/platforms.js` csdn：去掉 content 里的 `textarea.editor__inner`（避免误判），content 不以 iframe 开头；新增 `headlessUnsupported: true` 标记
- `publishToPlatform`：`mode==='auto' && platform.headlessUnsupported` → 强制回落 confirm，并 log 提示

### 关键事实：CSDN 编辑器在 headless 下拒绝加载
- headless 访问 `https://editor.csdn.net/md/` 会重定向到提示页「**编辑器不支持浏览器隐私模式，请使用普通模式访问！**」（probe-csdn-main.png 已截图确认）
- 因此 CSDN **只能走 confirm（有头）模式**，不能用 auto（无头）模式。
- 这也意味着：之前所有 `probe-csdn-body.js` / `probe-csdn-editor.js` 用 headless 跑出来的 DOM 都是**空页**（iframe/contenteditable/textarea 全为 0），不反映真实编辑器结构。真实 DOM 只能从 headed 截图（probe-csdn-editor.png / probe-csdn-headless.png）推断。
