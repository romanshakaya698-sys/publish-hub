# PublishHub · 自媒体多平台一键发稿（本地版）(暂时只支持企鹅号、大鱼号）

管理企鹅号、网易号等平台账号（登录态保存在本机），上传 Word/Markdown 稿件后，
勾选平台、点一下，即可自动完成「填标题 → 填正文 → 传封面」的发文流程。

## 启动

```bash
cd publish-hub
npm start
# 浏览器打开 http://localhost:3789
```

> 首次安装后需要先下载浏览器内核（只需一次）：
> `PLAYWRIGHT_BROWSERS_PATH=./browsers npx playwright install chromium`

## 使用流程

### 1. 账号管理（首次必做）

1. 进入「账号管理」页，点击平台卡片上的 **打开登录窗口**
2. 在弹出的浏览器窗口里扫码 / 输入账号完成登录
3. 登录态（cookie）自动保存在 `profiles/<平台id>/`，之后发稿不再需要登录
4. 平台踢下线后（cookie 过期），重新点一次登录窗口即可

**发文页地址**：脚本通过「发文页 URL」直接打开发文编辑器。
默认值是常见地址，如果平台改版导致打不开，自己打开该平台的发文页面，
复制浏览器地址栏 URL，填到卡片上的输入框里保存即可。

### 2. 上传稿件

「稿件库」→ 上传 docx / md / txt / html：
- 自动提取标题（第一个大标题），正文转为富文本 HTML
- docx 里的图片自动内联为 base64，粘贴到平台编辑器时会随正文进入
- 可预览、可编辑标题、可上传封面图

### 3. 一键发稿

稿件卡片 → 「发稿」→ 勾选平台 → 选择发布方式：

| 方式 | 说明 |
| --- | --- |
| 预填 + 人工确认（推荐） | 自动填好标题/正文/封面，停在发文页，你在浏览器里核对后自己点「发布」 |
| 全自动 | 自动点击发布按钮（平台有二次弹窗时可能需要人工点一下） |

发布过程与结果在「发布记录」页实时查看，每一步都有日志。

## 目录结构

```
publish-hub/
├── server.js            # Express 入口（API）
├── lib/
│   ├── platforms.js     # 平台定义（发文页地址、选择器，可被 settings 覆盖）
│   ├── browser.js       # Playwright 持久化浏览器管理（cookie 保留）
│   ├── publisher.js     # 发布引擎（填表/封面/提交，auto 与 confirm 两种模式）
│   ├── doc-parser.js    # docx/md/txt/html → 标题 + 正文 HTML
│   └── store.js         # JSON 数据持久化
├── public/              # 前端页面
├── data/                # 稿件库 / 发布记录 / 设置（自动生成）
├── profiles/            # 各平台浏览器 profile，登录态所在地（自动生成）
└── browsers/            # Chromium 内核（自动生成）
```

## 常见问题

- **发布失败提示「登录态失效」**：去「账号管理」重新登录该平台
- **标题/正文没填上**：平台改版导致选择器变化，编辑 `lib/platforms.js` 中对应平台的 selectors，
  或在 `data/settings.json` 中覆盖，无需改其他代码
- **提示「未配置发文页地址」**：在「账号管理」卡片里填入该平台发文页 URL 并保存
- **多平台同时发**：不同平台并行执行；同一平台排队串行，互不干扰

## 新增平台

1. 在 `lib/platforms.js` 的 `DEFAULTS` 数组里加一项（id、name、loginUrl、publishUrl、selectors）
2. 前端和 API 自动识别，无需其他改动

## 注意

- 本工具仅供个人发稿提效，请遵守各平台用户协议，勿用于垃圾内容批量分发
- `profiles/` 目录包含你的登录凭据，不要分享或上传
